# 4. Desenvolvimento Web

## Objetivo

Conhecer como a web funciona e aprender os fundamentos utilizados na construção de páginas e aplicações web. A trilha apresenta primeiro a estrutura e a apresentação de páginas e, em seguida, a programação no navegador e uma introdução ao lado do servidor.

## Pré-requisitos

- Recomenda-se conhecer os conceitos de [Introdução à Computação](introducao.md).
- É desejável ter estudado [Lógica de Programação](logica-programacao.md) e [Fundamentos de Programação](fundamentos-programacao.md), especialmente antes de avançar em JavaScript e back-end.
- Familiaridade básica com arquivos, pastas e uso do navegador.

## Conteúdo programático

### 4.1 Como a web funciona
- Internet e World Wide Web.
- Cliente, servidor e navegador.
- Endereços URL, DNS e HTTP/HTTPS.
- Requisições e respostas.
- Sites estáticos e aplicações dinâmicas.

### 4.2 HTML — estrutura
- Elementos, tags e atributos.
- Estrutura de um documento HTML.
- Títulos, parágrafos, listas, links e imagens.
- Formulários.
- HTML semântico e acessibilidade básica.

### 4.3 CSS — apresentação
- Seletores e propriedades.
- Cascata, especificidade e herança.
- Box Model.
- Unidades e tipografia.
- Flexbox e CSS Grid.
- Design responsivo.

### 4.4 JavaScript — interatividade
- Variáveis, tipos e operadores.
- Condicionais e laços.
- Funções e arrays.
- Objetos.
- DOM e manipulação de elementos.
- Eventos e interação com formulários.
- Requisições HTTP e consumo de APIs: introdução.

### 4.5 Ferramentas e fluxo de trabalho
- Editor de código e ferramentas do navegador.
- Terminal e linha de comando.
- Git e GitHub.
- Organização de arquivos e pastas.
- Publicação de páginas estáticas.

### 4.6 Próximos passos: front-end e back-end
- Responsabilidades do front-end.
- Noções de back-end e APIs.
- Servidores e rotas.
- Autenticação e segurança: conceitos iniciais.
- Integração com bancos de dados.

## Atividades práticas

- Crie uma página pessoal com título, parágrafos, links e imagens.
- Aplique CSS para organizar cores, espaçamentos e tipografia.
- Adapte a página para telas pequenas e grandes.
- Utilize JavaScript para validar um formulário ou responder a um clique.
- Publique uma página estática e compartilhe o endereço.

## Projetos sugeridos

1. **Página pessoal:** apresente seus interesses, habilidades e projetos.
2. **Página de divulgação:** crie uma página para divulgar uma iniciativa comunitária.
3. **Lista de tarefas:** permita adicionar, concluir e remover tarefas no navegador.
4. **Catálogo simples:** organize itens em cartões e implemente filtros básicos.

## Resultado esperado

Ao concluir esta trilha, você deverá compreender a estrutura básica de uma aplicação web e conseguir criar páginas responsivas com interatividade simples. O domínio profissional exige aprofundamento e prática contínua.
