# 3. Fundamentos de Programação

## Objetivo

Aprender os elementos essenciais de uma linguagem de programação e utilizá-los para criar programas simples. O foco está nos conceitos transferíveis entre diferentes linguagens, e não em decorar a sintaxe de uma única tecnologia.

## Pré-requisitos

- Recomenda-se concluir [Introdução à Computação](introducao.md) e [Lógica de Programação](logica-programacao.md).
- Ter acesso a um computador e a um ambiente no qual seja possível escrever e executar código.

## Escolha de uma linguagem

Para começar, escolha **uma linguagem** e mantenha o foco nela durante os primeiros exercícios. Python é uma opção acessível para iniciantes; C também é utilizado em cursos introdutórios para explorar conceitos de mais baixo nível. Não é necessário estudar várias linguagens ao mesmo tempo.

## Conteúdo programático

### 3.1 Primeiros programas
- Estrutura básica de um programa.
- Sintaxe e semântica.
- Execução de código.
- Comentários e legibilidade.
- Entrada e saída de dados.

### 3.2 Dados e operações
- Variáveis, constantes e tipos.
- Conversão de tipos.
- Operadores e expressões.
- Manipulação básica de textos.

### 3.3 Controle de fluxo
- Condicionais.
- Laços de repetição.
- Aninhamento de estruturas.
- Interrupção e controle de repetições.

### 3.4 Funções e organização
- Declaração e chamada de funções.
- Parâmetros e valores de retorno.
- Escopo de variáveis.
- Divisão de um programa em partes menores.

### 3.5 Estruturas de dados iniciais
- Listas e vetores.
- Dicionários ou estruturas equivalentes.
- Percorrer e modificar coleções.
- Noções de organização de dados.

### 3.6 Qualidade e depuração
- Leitura de mensagens de erro.
- Depuração (debugging).
- Testes com diferentes entradas.
- Nomes significativos e código legível.
- Noções de tratamento de erros.

## Atividades práticas

- Escreva um programa que receba o nome de uma pessoa e exiba uma saudação.
- Crie uma calculadora com as quatro operações básicas.
- Desenvolva um programa que identifique números pares e ímpares.
- Faça um programa que percorra uma lista de valores e calcule a soma.
- Reescreva um exercício utilizando funções para separar responsabilidades.

## Projeto sugerido

**Agenda de contatos no terminal:** crie um programa simples que permita adicionar, listar, pesquisar e remover contatos. Comece armazenando os dados em memória; posteriormente, poderá estudar como persistir essas informações em arquivos ou bancos de dados.

## Resultado esperado

Ao concluir esta etapa, você deverá conseguir escrever, executar, testar e corrigir programas pequenos, além de compreender os principais elementos presentes em linguagens de programação.
