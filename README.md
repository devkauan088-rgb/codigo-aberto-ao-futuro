# Sobre o projeto

O **Código Aberto ao Futuro** é uma iniciativa educacional comunitária desenvolvida originalmente como parte das atividades de extensão universitária do curso de Análise e Desenvolvimento de Sistemas (ADS) da Universidade Paulista (UNIP).

O projeto nasceu de uma percepção simples: embora a internet disponibilize uma quantidade enorme de materiais educacionais gratuitos, muitas pessoas não sabem onde encontrá-los, como identificar conteúdos de qualidade ou, principalmente, por onde começar.

Nosso propósito é ajudar a resolver esse problema.

Queremos democratizar o acesso ao conhecimento tecnológico por meio da organização e recomendação de recursos educacionais disponíveis gratuitamente na internet.

Inspirado em iniciativas como a [Open Source Society University (OSSU)](https://cs.ossu.dev/), este projeto busca organizar diferentes materiais em trilhas de aprendizagem estruturadas, permitindo que estudantes desenvolvam seus conhecimentos progressivamente.

### Nossa missão

Conectar pessoas ao conhecimento, tornando o aprendizado de tecnologia mais acessível, organizado e independente.

### Nossa proposta

O Código Aberto ao Futuro **não pretende substituir escolas, universidades ou plataformas de ensino**.

Nossa função é atuar como um guia educacional.

Organizamos e recomendamos cursos, livros, documentações, videoaulas e outros materiais produzidos por instituições, professores e comunidades.

Os conteúdos permanecem em suas respectivas plataformas de origem. Aqui, você encontrará orientações sobre o que estudar, em qual ordem estudar e onde encontrar os materiais.

# Como utilizar este guia

Este repositório foi pensado para pessoas que desejam aprender tecnologia de maneira independente, mesmo sem experiência anterior.

Você não precisa conhecer programação para começar.

Recomendamos seguir estas etapas:

1. **Escolha uma trilha:** identifique a área que deseja estudar.
2. **Respeite os pré-requisitos:** alguns conteúdos exigem conhecimentos adquiridos anteriormente.
3. **Acesse os materiais:** cada etapa apresenta links para cursos e recursos externos.
4. **Estude no seu ritmo:** organize sua rotina de acordo com sua disponibilidade.
5. **Pratique:** procure desenvolver pequenos projetos para consolidar o conhecimento.
6. **Acompanhe seu progresso:** marque as etapas concluídas e identifique seus próximos objetivos.

> Os links disponibilizados direcionam para os sites originais dos cursos e materiais. O Código Aberto ao Futuro não hospeda nem reproduz esses conteúdos.

# Metodologia de aprendizagem

Nossa organização segue uma estrutura progressiva, dividida em diferentes etapas.

| Etapa | Objetivo |
|---|---|
| Introdução | Conhecer a computação e o universo da tecnologia. |
| Fundamentos | Desenvolver raciocínio lógico e conhecimentos essenciais. |
| Desenvolvimento | Aprender linguagens, ferramentas e tecnologias. |
| Especialização | Aprofundar conhecimentos em áreas específicas. |
| Prática | Aplicar o conhecimento em projetos reais. |

Cada trilha poderá apresentar:

- **Objetivo:** o que você deverá aprender.
- **Conteúdo programático:** assuntos abordados.
- **Pré-requisitos:** conhecimentos necessários.
- **Materiais:** cursos, livros e documentações recomendados.
- **Carga horária:** estimativa de dedicação, quando informada pela fonte.
- **Projetos:** atividades práticas para consolidar o aprendizado.

# Currículo de estudos

O currículo será organizado em áreas de conhecimento, respeitando a progressão natural do aprendizado.

As trilhas abaixo representam a estrutura inicial do projeto. Nem todas possuem uma curadoria completa neste momento.

## 1. Introdução à computação

**Objetivo:** compreender o funcionamento dos computadores, conhecer os fundamentos da computação e descobrir as possibilidades da área de tecnologia.

**Conteúdos:**
- O que é Ciência da Computação?
- História e evolução dos computadores.
- Hardware e software.
- Sistemas operacionais.
- Representação de dados.
- Introdução à internet.

**Materiais recomendados:**

- [Harvard CS50](https://cs50.harvard.edu/x/) — Introdução à Ciência da Computação.
- [OSSU – Computer Science](https://cs.ossu.dev/) — Currículo de Ciência da Computação.
- [Como Computadores Funcionam - Fábio Akita](https://youtu.be/8G80nuEyDN4?si=d--8lAOCvGye6S7d) — Como Computadores Funcionam.

## 2. Lógica de programação

**Objetivo:** desenvolver o raciocínio lógico necessário para compreender problemas e construir soluções utilizando algoritmos.

**Conteúdos:**
- Introdução aos algoritmos.
- Variáveis e constantes.
- Tipos de dados.
- Operadores aritméticos e lógicos.
- Estruturas condicionais.
- Estruturas de repetição.
- Funções e procedimentos.
- Vetores e matrizes.

**Materiais recomendados:**

- [Curso em Vídeo](https://www.cursoemvideo.com/curso/curso-de-algoritmo/) — Curso Introdutório de Lógica de Programação e Algoritmos.
- [Harvard CS50 - PTBR](https://cs50xemportugues.github.io/2024/) — Fundamentos de Ciência da Computação e programação.

## 3. Fundamentos de programação

**Objetivo:** aprender os conceitos fundamentais das linguagens de programação e desenvolver a capacidade de construir aplicações.

**Conteúdos:**
- Sintaxe e semântica.
- Estruturas de dados.
- Modularização.
- Programação estruturada.
- Programação orientada a objetos.
- Tratamento de erros.
- Depuração de código.
- Introdução à complexidade de algoritmos.

**Possíveis linguagens de estudo:**
- Python.
- Java.
- C.
- JavaScript.

**Materiais recomendados:**

- [OSSU – Computer Science](https://cs.ossu.dev/).
- [Curso em Vídeo - Linguagem Java](https://www.cursoemvideo.com/curso/java-basico/).

## 4. Desenvolvimento Web

**Objetivo:** compreender o funcionamento da Web e aprender a desenvolver páginas e aplicações web.

### Front-end

**Conteúdos:**
- Internet
- HTML5.
- CSS3.
- JavaScript.
- Design responsivo.
- Manipulação do DOM.
- Acessibilidade.
- Consumo de APIs.

### Back-end

**Conteúdos:**
- Funcionamento de servidores.
- Requisições HTTP.
- APIs REST.
- Autenticação e autorização.
- Integração com bancos de dados.
- Segurança de aplicações.

**Materiais recomendados:**

- [Como a internet funciona - Fábio Akita](https://youtu.be/0TndL-Nh6Ok?si=j1LpBGOzGGF0dmjP).
- [The Odin Project](https://www.theodinproject.com/).
- [MDN Web Docs](https://developer.mozilla.org/).
- [freeCodeCamp](https://www.freecodecamp.org/).

## 5. Banco de dados

**Objetivo:** compreender como informações são armazenadas, organizadas e manipuladas em sistemas computacionais.

**Conteúdos:**
- Fundamentos de bancos de dados.
- Modelagem de dados.
- Modelo entidade-relacionamento.
- SQL.
- Consultas e operações CRUD.
- Normalização.
- Relacionamentos.
- Introdução a bancos NoSQL.

**Materiais recomendados:**

- [SQLBolt](https://sqlbolt.com/).
- [Documentação do PostgreSQL](https://www.postgresql.org/docs/).

## 6. Engenharia de software

**Objetivo:** compreender os processos, métodos e ferramentas utilizados no desenvolvimento e na manutenção de sistemas.

**Conteúdos:**
- Ciclo de vida do software.
- Levantamento de requisitos.
- Modelagem de sistemas.
- UML.
- Arquitetura de software.
- Controle de versão com Git.
- Testes de software.
- Metodologias ágeis.
- Documentação técnica.

**Materiais recomendados:**

- [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/).
- [Pro Git](https://git-scm.com/book/pt-br/v2).
- [Aprenda Git Branching] (https://learngitbranching.js.org/).

## 7. Estudos avançados e especialização

Após construir uma base sólida, você poderá direcionar seus estudos para áreas específicas da tecnologia.

Algumas possibilidades:

| Área | Principais assuntos |
|---|---|
| Inteligência Artificial | Machine Learning, Deep Learning e redes neurais. |
| Ciência de Dados | Estatística, análise e visualização de dados. |
| Cibersegurança | Segurança de redes, sistemas e aplicações. |
| Desenvolvimento Mobile | Android, iOS e aplicações multiplataforma. |
| Computação em Nuvem | Cloud Computing, infraestrutura e serviços. |
| DevOps | Automação, integração e entrega contínua. |
| Sistemas e Redes | Arquitetura de computadores, redes e sistemas operacionais. |

**Materiais de referência:**

- [OSSU](https://cs.ossu.dev/).
- [freeCodeCamp](https://www.freecodecamp.org/).
- [MIT OpenCourseWare](https://ocw.mit.edu/).

# Projetos práticos

Aprender conceitos é importante, mas colocá-los em prática é fundamental.

Ao longo dos estudos, recomendamos desenvolver projetos que permitam aplicar os conhecimentos adquiridos.

Algumas sugestões:

| Nível | Projeto | Conhecimentos aplicados |
|---|---|---|
| Iniciante | Calculadora | Lógica de programação. |
| Iniciante | Lista de tarefas | Variáveis, funções e estruturas de dados. |
| Intermediário | Página pessoal | HTML, CSS e JavaScript. |
| Intermediário | Sistema de cadastro | Programação e banco de dados. |
| Avançado | Aplicação Web completa | Front-end, back-end e APIs. |

O objetivo é construir gradualmente um portfólio que demonstre sua evolução como estudante e desenvolvedor.


# Comunidade e contribuições

O *Código Aberto ao Futuro* é um projeto que pretende crescer com a participação da comunidade.

Acreditamos que o conhecimento deve ser compartilhado e que diferentes pessoas podem contribuir para tornar os materiais educacionais mais acessíveis.

Você pode contribuir de diversas maneiras:

- Sugerindo cursos e materiais gratuitos.
- Identificando links desatualizados.
- Recomendando melhorias nas trilhas.
- Corrigindo informações.
- Sugerindo novas áreas de estudo.
- Melhorando a documentação.

### Como contribuir?

1. Faça um fork deste repositório.
2. Crie uma branch para sua contribuição.
3. Realize as alterações desejadas.
4. Envie suas alterações para o GitHub.
5. Abra um Pull Request explicando suas modificações.

Toda contribuição construtiva será bem-vinda!
